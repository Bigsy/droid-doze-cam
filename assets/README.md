# PhoneCam app icon

The icon combines a white smartphone silhouette and a blue/cyan camera lens on a midnight-blue rounded tile. It was generated with the built-in OpenAI image generation tool on 2026-09-09, then resized with macOS `sips` and packaged with `iconutil`. The transparent background is preserved.

- `phonecam.png`: 1024 × 1024 PNG source used in the README.
- `PhoneCam.icns`: macOS icon with standard 16–1024px representations.
- `../scripts/make-icon.sh`: regenerate ICNS after changing the PNG.

The artwork is distributed under the repository's MIT license. No external brand logo or proprietary reference image was used.

## Original generation prompt

```text
Use case: logo-brand. Create ONE finished macOS application icon for PhoneCam, an open-source app that turns an existing Android phone or iPhone into a Mac camera. Asset: production app icon, square 1024 by 1024, not a mockup or icon sheet. A single bold friendly white smartphone silhouette contains one beautifully simple large camera lens; the lens is the focal point. Restrained modern macOS visual language, smooth softly rounded geometry, crisp edge definition, premium but calm. Deep midnight blue rounded-square tile with a subtle indigo-to-blue light gradient, white phone outline and a cyan lens highlight, minimal gentle dimensionality. The phone is upright and slightly wider than an ordinary handset so the camera-lens motif remains very readable at 32 pixels. Balanced centered composition, generous clean padding, icon tile occupies about 88 percent of image width with rounded corners. Outside the rounded-square tile is genuinely transparent alpha, not a checkerboard. No text, no letters, no numbers, no company logos, no cables, no tiny detail, no scenery, no extra devices, no outer drop shadow, no watermark. Keep this suitable for an installed Mac utility, elegant and extremely simple.
```
