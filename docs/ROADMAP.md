# Roadmap

This is a list of priorities, not a release schedule.

## Current developer preview

- Android USB capture while the tested phone is locked with its display off.
- On-demand macOS camera extension and login service.
- Menu bar setup, camera selection and service status.
- Local rotation, mirroring, zoom and adjustable background blur.
- Native preview and optional Syphon output.
- Local build, test, signing and notarization scripts.

## Next priorities

1. Validate the current source with a full build and signed camera installation.
2. Test upgrades and a clean Mac installation of the release ZIP.
3. Expand device coverage, reconnect testing, receiving apps and longer sessions.
4. Improve setup diagnostics based on reproducible user reports.

Windows is outside the current scope. A port needs native capture and camera-output backends; see [platform assessment](PLATFORMS.md).
